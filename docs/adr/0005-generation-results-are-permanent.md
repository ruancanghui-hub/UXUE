# 生成结果不进撤销栈，并回写到所有历史快照

生成要花钱和时间，结果可能在用户做了别的操作之后才到达。如果把"生成结果写入文档"当成一条普通的撤销记录，撤销到它之前就会把已经付费得到的版本删掉；如果只写进当前状态，撤销任何更早的操作又会恢复成没有这些版本的旧快照。因此我们把生成结果做成"永久改动"：`DocumentStore.applyPermanent` 把一个只做追加的函数（输出图像卡不存在就新建，版本没有就追加）套用到当前状态和撤销栈里的每一个快照上，"把当前版本切到新结果"只作用于当前状态（以及恰好等于当前状态的栈顶）。效果是撤销只会把当前版本切回去，生成的版本永远留在版本栈里，要去掉只能显式删除。

## Consequences

- 撤销到提示词卡创建之前，提示词卡会消失，但它生成的输出图像卡和版本仍然在画布上。
- 追加函数必须是幂等的（同一结果套用两次不变），因为同一个快照对象可能同时出现在相邻两条历史记录里。
