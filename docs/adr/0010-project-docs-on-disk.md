# 项目文稿落在磁盘 Markdown，不进画布与 project.json

暗夜精灵的画布对象适合图像、提示词、页面框这类可摆放、可生成的实体。PRD、界面简报、设计规范、AGENTS.md 是给人（和外部 Agent）读的长文，若做成「文档卡」会挤占区域、拖垮图层列表，也难被 Cursor/Claude 直接打开。因此四类**项目文稿**以约定路径的 Markdown 存在项目目录里（`docs/*.md` 与根目录 `AGENTS.md`），软件只提供列表、阅读/编辑、复制与（对设计规范）一条生图入口；索引不写入 `project.json`。主题说明仍只在 `themes/`，与设计规范文稿分工不同。
