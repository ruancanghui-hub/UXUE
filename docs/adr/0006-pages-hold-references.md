# 页面框里放的是素材引用卡片，不是把图像卡移进去

把核心素材放进页面框时，我们不移动图像卡本身，而是新建一张"素材引用"卡片（`kind: 'ref'`），它记下指向哪张图像卡、属于哪个页面框，显示的是那张图像卡的当前版本。这样同一个核心素材可以出现在多个页面里，在版本栈里换当前版本时所有页面一起更新（PLAN 里"引用，跟随当前版本"），核心素材区也保持完整。引用本身是普通卡片，选中、移动、缩放、微调、删除、撤销都直接复用；页面框和引用之间的关系由几条规则维持：拖动 / 缩放 / 微调页面框时带上它的引用，删除页面框或被引用的图像卡时连带删除引用，复制页面框时一起复制引用，绘制和点击时引用总是排在自己的页面框后面（`renderOrder`），引用拖出页面时按中心点重新认页面。

## Considered Options

- 页面框作为容器，图像卡直接移进去（像 Figma 的 Frame）：交互更直观，但一张素材只能在一个页面里，也失去了"换版本全页面跟着变"。
