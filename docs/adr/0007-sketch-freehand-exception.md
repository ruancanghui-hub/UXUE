# 布局草图允许手绘笔迹和文字，作为"不做绘制"的有限例外

ADR-0002 定了暗夜精灵不做矢量绘制。布局草图需要在纸上随手画几笔、写几个字的速度，只靠拖框不够，所以在页面框里开放画笔、橡皮和文字三个工具，但把它们限定为草图素材：每一笔存成点序列（归一化到外接框），只有一种颜色、两种粗细，没有贝塞尔曲线、样式面板、对齐和组件；它们只在"草图转线框"时被画进示意图交给 AI 去理解，从不进入导出的 PNG、SVG 和素材包；出图换成底稿后自动隐藏。这样构思速度够快，又不会把画布慢慢变成一个绘图软件。

## Considered Options

- 只用拖框加命名（原来的做法）：最守 ADR-0002，但画不出"这里大概一个圆、那里一条分隔线"这种随手的意思。
- 画在一张位图上：橡皮能擦局部，但一笔不能单独移动、删除，撤销粒度太粗，也要多管理一张随时变化的图片文件。
