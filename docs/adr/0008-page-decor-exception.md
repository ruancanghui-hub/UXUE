# 页面框内允许圆角填充矩形作为页面装饰

ADR-0002 定了暗夜精灵不做矢量设计编辑器。排高保真页面时经常需要一块色底垫在图标或卡片下面，只靠素材引用不够，而完整形状工具又会把画布拖成 Figma。因此在页面框里开放**页面装饰**：仅圆角填充矩形（位置、宽高、填充色、圆角半径），用 R 拖出；不对齐成路径、描边样式库或自动布局。装饰进入导出的 PNG 与分层 SVG（SVG 为矢量 `<rect>`），便于拖进 Figma 继续精修。草图笔迹（ADR-0007）仍只服务「草图转线框」、不进导出——两者分工不同。

## Considered Options

- 不做底板，全部在 Figma 里补：最守 0002，但排板阶段看不出图标压在色块上的效果，导出后还要重摆一层。
- 伪装成位图素材引用：实现简单，但圆角在缩放和导出时发糊，也占核心素材区。
- 完整形状工具：功能最全，直接违背「不做矢量设计编辑器」。
