# 规格：界面感觉（秩序 · 克制 · 从容）

> 术语以 [`CONTEXT.md`](../../CONTEXT.md) 为准。源说明见仓库 `构思/三种感觉.md`。  
> Grill：可多选；Q1=B，其余推荐。

## 0. 一句话

提示词卡生成时可多选「秩序 / 克制 / 从容」，提交时按固定顺序附加短后缀，与主题规则独立。

## 1. 决策

| 项 | 选择 |
|---|---|
| 选择 | 可多选，可全不选 |
| 字段 | `PromptSettings.feelings: ('order'\|'restraint'\|'calm')[]` |
| 拼接序 | 秩序 → 克制 → 从容 |
| 注入 | 生成时后缀，不改正文；`themeSuffix` 之后 |
| 文案 | 内置短后缀 |
| 专用路径 | 转线框、设计规范图等 `feelings: []` |
| 过期 | 改感觉会改变 expected 全文 → 可标过期 |
| 默认 | 新建卡 `[]` |
