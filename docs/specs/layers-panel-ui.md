# 规格：图层面板可读性（图标 · 树线 · 折叠）

> 2026-11-14 grill：Q1–Q12 全按推荐。不改领域模型与层序/拖拽规则。

## 0. 一句话

左侧图层用 SF 风线框图标、缩进树线、区域/页面/分组折叠，让类型和父子关系一眼能分清。

## 1. 决策

| # | 选择 |
|---|---|
| 范围 | 视觉 + 折叠；信息架构与拖拽规则不动 |
| 图标 | 内嵌 SVG，约 10 个类型；不接 iconfont / 图标库 |
| 层级 | 类型图标（略有色差）+ 缩进树线；图像/引用用缩略图，引用角标 |
| 不做 | 显隐、锁定、行内重命名、拖动手柄、小分组标题 |
| 折叠 | 区域 / 页面框 / 分组框；默认展开；按项目目录记 localStorage |
| 热区 | 仅 ▾/▸ 折叠；点行选中，双击定位 |
| 装饰槽 | 28×28 真实填充色块 |

## 2. 验收

- [ ] 各类型有对应线框图标或缩略图/色块；引用有角标
- [ ] 缩进子行有细竖线树线
- [ ] 区域、有子项的页面/分组可折叠；箭头点击不触发行选中
- [ ] 折叠状态换项目互不影响，同项目重开仍在
- [ ] 同页装饰↔引用拖拽仍可用
- [ ] `npm test` / `typecheck` 通过
