# 规格：转线框

> 术语以 [`CONTEXT.md`](../../CONTEXT.md) 为准：**转线框、低保真原型、底稿来源、区块截图**。  
> 决策来自 2026-11-13 grill 会话（Q1–Q11 全部采纳推荐项）。

## 0. 一句话

把一张截图（通常是借鉴的成品截图）用当前生图供应商和固定提示词改画成黑白线描的**低保真原型**：保留布局和原文字，图标、插画重画成线描，不附加主题规则。走普通的提示词卡 → 输出图像卡链路；可以一键换成页面框的低保真原型。

## 2. 数据模型

- `PromptCard.purpose: 'wireframe' | null` —— 标记这张提示词卡是转线框。
- `PageCard.baseCardId: string | null` —— 底稿来自哪张图像卡（用线框当前版本做底稿时用）。
- `PageCard.wireframePromptId: string | null` —— 从页面框发起转线框时等待的提示词卡；它的输出第一次出版本就换底稿并清空。
- `BlockCard.cropBaseVersionId: string | null` —— 截图时页面框底稿的版本；和现在的底稿不同就是截图过时。
- 解析时指向不存在的卡置 null；schema 仍为 2。

## 3. 操作

- `createWireframePrompt(state, imageCardId)`：在图像卡右侧建提示词卡（固定提示词、`useTheme: false`、1 张、跟随比例、质量中、`purpose: 'wireframe'`）。
- `wireframeFromPage(state, pageId)`：把底稿复制成图像卡放在页面框左侧（整条链不压住页面框），建转线框提示词卡，页面框记下 `wireframePromptId`。
- `applyGenerationResult` 新建输出卡时：若某页面框的 `wireframePromptId` 等于这张提示词卡，换底稿（`base`、`baseCardId`、`baseSource: 'borrowed'`，跟随原型尺寸时高度按新比例），清空 `wireframePromptId`。幂等。
- `setPageBaseFromCard(state, pageId, imageCardId)`：用图像卡当前版本做底稿；是转线框结果时底稿来源设为借鉴。
- `newPageFromImageCard(state, imageCardId)`：同上规则新建页面框。

## 4. UI

- 图像卡属性：「转线框」（提交生成）、「用这张图新建页面框」。
- 页面框低保真原型一栏：「转线框」；有 `baseCardId` 且该图像卡当前版本不是底稿时显示「用线框当前版本做底稿」。
- ⌘K：「转线框」（选中一张图像卡时）。
