# 规格：排板对齐 · 数字尺寸 · 页面装饰 · 导出增强

> 术语以 [`CONTEXT.md`](../../CONTEXT.md) 为准：**页面框、素材引用、页面装饰、导出**。  
> 决策来自 2026-11-14 grill 会话（Q1–Q12 全部采纳推荐项）。  
> 相关：[`ADR-0002`](../adr/0002-ai-orchestration-not-design-editor.md)、拟新增 ADR-0008（页面装饰窄例外）。

## 0. 一句话

在页面框里拖素材引用时出现智能对齐线；属性里用数字和预设改图标宽高；用 R 拖出圆角有填充的**页面装饰**当底板；导出 SVG 时带上装饰矢量层和素材，默认不带低保真，方便拖进 Figma。

## 1. 已锁定的决策

| # | 决策 | 选择 |
|---|---|---|
| Q1 | 对齐线 | 拖素材引用时智能对齐：其它素材边缘/中心 + 页面框边缘/中心（不做网格） |
| Q2 | 数字大小 | 宽高可填；默认等比锁定；预设 24 / 48 / 64 / 80 |
| Q3 | 圆角矩形 | 页面框内**页面装饰**（填充 + 圆角），不是完整形状工具 |
| Q4 | 进 Figma | 增强现有分层 SVG；用法仍是导出后拖进 Figma（不做插件） |
| Q5 | 对齐范围 | 同页素材引用 / 区块 / 页面装饰 + 页面框；拖动与拖画时吸附（约 6 逻辑像素，且不少于 8 屏像素） |
| Q6 | 实体 | 新实体「页面装饰」：位置、宽高、填充色、圆角；非图像卡 |

## 2. 领域词（开干时写入 CONTEXT）

**页面装饰**:
页面框里的一块圆角填充矩形，用来垫在图标或卡片下面。只属于一个页面框；有位置、宽高、填充色、圆角半径。不是图像卡，也不是素材引用。叠在低保真之上、素材引用之下。进入导出的 PNG 与分层 SVG（SVG 里是矢量圆角矩形）；草图笔迹和草图文字仍不进入导出。

**导出**（修订）:
把一个页面框写成整页 PNG、分层 SVG（背景、可选低保真、页面装饰矢量层、每个素材一层）、素材包和坐标清单。默认不包含低保真原型层；可在页面属性勾选包含。SVG 可直接导入 Figma。

## 3. 实现要点

### 3.1 数据

- 新增 `DecorCard`（`kind: 'decor'`）：`id, x, y, width, height, pageId, fill, cornerRadius, z`（或用 cards 数组顺序表示同类层序）。
- `CanvasCard` 联合类型纳入；`parseProject` 兼容旧项目（无 decor）。
- `PageCard` 增加 `exportIncludeBase: boolean`，默认 `false`（旧项目解析为 `false`，改变「默认带低保真」行为——与 Q7 一致）。

### 3.2 对齐线

- 拖动 / 缩放**素材引用**（及可选：拖页面装饰）时，相对同 `pageId` 其它素材引用与页面框四边/中心计算候选线。
- 屏幕像素阈值 ≈ `6 * (page.width / logicalWidth)` 或统一 6 画布单位再按 zoom 换算到屏幕；吸附后画品红/主题色细线，松手清除。
- 不吸附区块、不跨页。

### 3.3 数字尺寸（Inspector · 素材引用）

- 显示逻辑像素宽高（相对设备逻辑尺寸换算，或直接画布单位标注清楚「画布单位」——与现有页面逻辑尺寸一致：优先显示相对页面的逻辑 px）。
- 锁定比例开关；预设按钮写入边长（解锁时只改宽或按较短边）。
- 提交时写回 `RefCard.width/height`，保持中心或左上锚点与现有缩放手柄一致（沿用现有 resize 锚点：左上不动）。

### 3.4 页面装饰

- `Tool` 增加 `'decor'`，快捷键 R；仅在命中页面框内开始拖拽时创建。
- 默认 `fill` = 生效主题第一色，否则 `#E8E8ED`；`cornerRadius = 12`。
- Inspector：填充色、圆角、宽高数字；「上移 / 下移一层」仅同类。
- 画布绘制：`roundRect` 填充；选中有手柄。
- 删除页面框时级联删除其 decor（与 block/stroke/ref 一致）。

### 3.5 导出

- `PageExportPlan` 增加 `shapes: { name, x, y, width, height, fill, cornerRadius }[]`（导出像素坐标）。
- PNG：在 background 与 base（若勾选）之后、素材之前 composite 圆角矩形（sharp 可用 SVG buffer 叠加）。
- SVG：`<g id="装饰">` 下每项 `<rect rx ry fill/>`；低保真 `<image>` 仅当 `exportIncludeBase`。
- manifest 可附带 shapes 逻辑坐标。

### 3.6 文档

- `docs/adr/0008-page-decor-exception.md`
- 更新 `CONTEXT.md` 词条；`PLAN.md` 记一条里程碑（若开干时惯例仍更新 PLAN）。

## 4. 验收

- [x] 同页拖素材引用出现对齐线并吸附边缘/中心/页面框；松手线消失。
- [x] 选中素材引用可填宽高、锁定比例、一点预设 24/48/64/80。
- [x] R 在页面框内拖出圆角底板；可改色与圆角；层序在装饰之间可调且不压过素材。
- [x] ⌘⇧E 导出：SVG 含装饰矢量层 + 素材图；默认无低保真；勾选后有低保真层；PNG 合成顺序正确。
- [x] 旧项目可打开；`npm test` / `typecheck` 通过（`check:m5` 手工回归）。

## 5. 非目标

- 8pt 网格、跨页对齐、完整形状工具、Figma 插件、导出后自动打开 Finder/Figma。
