# 规格：页面区块（拆解 → 为区块写提示词 → 生成放回）

> 术语以仓库根目录 [`CONTEXT.md`](../../CONTEXT.md) 为准：**区块、区块组、拆解、底稿来源、为区块写提示词、区块截图**。  
> 决策来自 2026-11-13 grill 会话（Q1–Q17 全部采纳推荐项）。

## 0. 一句话

选中一个有低保真原型的页面框 →「拆解」：助手看图，在页面框里放一组带类型的**区块**（虚线框）→ 用户修正 →「为区块写提示词」：按区块裁出**区块截图**，放进核心素材区一个分组框，助手一次看完全部截图，为每个区块写一张绑定好截图的提示词卡 → 用户生成 → 每个区块的输出图第一次有版本时，自动在区块位置放一个素材引用。生效主题卡照常附加；助手不发起生成。

## 1. 已锁定的决策

| Q2 | 底稿 | 自己的线框或借鉴截图都当低保真原型 |
| Q3 | 谁划区块 | 助手提议 + 手动增删改 |

| Q7 | 加工链位置 | 核心素材区，每个页面一个分组框「页面名 · 区块」，每行：截图 → 提示词卡 → 输出 |

| Q11 | 入口与重拆 | 属性面板按钮 + 助手快捷按钮；重拆时保留已有输出的区块，只替换还没生成过的 |

## 2. 数据模型

```ts
type BlockType = 'hero' | 'icon' | 'tile' | 'tabbar' | 'illustration' | 'other';

interface BlockCard {
  kind: 'block';
  id: string;
  name: string;              // 「Banner」「金刚位 1」…；other 类型时就是自填名字
  x: number; y: number; width: number; height: number;   // 画布坐标
  pageId: string;            // 只属于一个页面框；页面框删掉区块一起删
  blockType: BlockType;
  group: string | null;      // 区块组名，比如「金刚位」
  cropCardId: string | null; // 区块截图图像卡
  /** 截图时区块相对页面框的位置（0–1）；和现在不同就是截图过时 */
  cropRect: { x: number; y: number; width: number; height: number } | null;
  promptCardId: string | null;
}

interface PageCard { /* 现有字段 */ baseSource: 'own' | 'borrowed' }
```

- 区块「已有输出」= `promptCardId` 指向的提示词卡有 `outputCardId`。
- 解析：`pageId` 指向的页面框不存在 → 丢弃区块；`cropCardId` / `promptCardId` 指向的卡不存在 → 置 null。
- schema 仍为 2（新增的 kind 与可选字段旧版本读不到也不会损坏）。

## 3. 文档操作

- `applyDecomposition(state, pageId, drafts)`：删掉该页面里**没有输出**的区块，按草稿（0–1000 归一化坐标）新建区块，排在页面框子元素最上层。
- 页面框移动 / 缩放 / 复制 / 删除：区块和引用一样跟随（`withPageChildren`、`duplicateCards`、`removeCards`）。复制出的区块不带截图、提示词链接。
- 单独缩放一个区块时允许非等比。
- `blockCropStale(block, page)`：`cropRect` 与当前相对位置差超过 0.5% 即过时。
- 删除截图图像卡或提示词卡时，区块对应字段置 null。
- `applyGenerationResult` 新建输出图像卡时：若有区块 `promptCardId === result.promptCardId`，同时在区块位置新建素材引用（幂等，可套用到撤销栈每个快照）。

## 4. 区块截图

- 新 `ImportSource`：`{ kind: 'crop'; name; file; rect: { left, top, width, height } }`（像素，相对低保真原型原图）。主进程校验路径，worker 用 sharp `extract` 后按普通导入流程写原图与缓存。
- 「为区块写提示词」：为每个没有截图（或截图过时）的区块裁图；一条撤销记录内放入分组框「页面名 · 区块」与截图卡；然后请求助手。
- 「更新截图」：给已有截图卡追加一个新版本并设为当前（下游自动已过期）。

## 5. 助手

- 请求新增 `task: 'chat' | 'decompose' | 'blockPrompts'` 与 `blocks` 上下文（类型、组、名字、底稿来源）。
- 结构化输出新增 `blocks: { name, type, group, x, y, width, height }[]`（坐标 0–1000，相对第 1 张图）。
- `decompose`：只看低保真原型，返回 blocks，theme null、prompts 空。
- `blockPrompts`：第 N 张图就是第 N 个区块截图；每个区块一条提示词，`inputIndex = N`，正文用 `{{Image 1}}`；同组风格一致；借鉴截图只借布局；图标类要求纯色背景（生效主题卡的浅底色）；不重复主题规则。
- 本地模拟：拆解返回一套固定的首页布局；写提示词按类型套模板。

## 6. UI

- 画布：区块是页面框里的虚线框 + 左上角类型标签；截图过时时标签带「截图过时」。
- 页面框属性：「拆解」「为区块写提示词」按钮、底稿来源开关、区块列表。
- 区块属性：名字、类型、区块组、截图（缩略图 / 更新截图 / 选中截图）、提示词卡（选中）、删除。
- 助手快捷按钮：「拆解选中的页面」。
