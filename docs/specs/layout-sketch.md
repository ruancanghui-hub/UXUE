# 规格：布局草图 → 草图转线框

> 术语以 [`CONTEXT.md`](../../CONTEXT.md) 为准：**布局草图、区块、转线框、页面框、低保真原型**。  
> 决策来自 2026-11-14 grill 会话（Q1–Q6 全部采纳推荐项）。

## 0. 一句话

在空白页面框（可选多种 iPhone 尺寸）上用区块工具（B）拖出框并命名，摆出页面要放什么；点「草图转线框」，程序把框和名字画成示意图，AI 按名字画成黑白线框，结果自动成为页面框的低保真原型（底稿来源：自己的线框），区块保留，接着拆解、写区块提示词或列素材清单。

## 1. 已锁定的决策

| # | 决策 | 选择 |
|---|---|---|
| Q1 | 怎么画 | 拖框加命名（区块），不做自由画笔；遵守 ADR-0002 |
| Q2 | 画板 | 复用空白页面框；补 iPhone SE / mini / 16 / Plus·Pro Max 预设 |
| Q3 | 转完之后 | 自动换成页面框底稿，底稿来源设为自己的线框，区块保留 |
| Q4 | 画框 | 区块工具 B：页面框里拖出框，名字输入框自动聚焦；可连续画，V / Esc 退出；按在已有区块或选中框的角上照常移动、缩放 |
| Q5 | 转线框 | 本地按逻辑尺寸 ×3 画示意图（白底灰框加名字）→ 图像卡放页面框左侧 → 提示词卡「草图转线框」（固定提示词、不附加主题）→ 直接生成 → 首版自动换底稿 |
| Q6 | 一组 | 一个框可代表一组（「金刚位 ×4」），线框出来后再拆解细分（草图框未出图，会被整体替换） |

## 2. 实现要点

- `DEVICE_PRESETS` 新增 `iphone-max`（430×932）、`iphone-mini`（375×812）、`iphone-se`（375×667）。
- `PromptCard.purpose` 新增 `'sketch'`；从页面框发起的转线框链复用同一套（`pageWireframeChain`），出图换底稿时 `sketch` 设为自己的线框、`wireframe` 设为借鉴。
- `ImportSource` 新增 `{ kind: 'sketch', name, width, height, boxes }`，worker 用 SVG 画成 PNG，走普通导入写原图和缓存。
- `createBlockAt` 建区块；画布 `Tool` 新增 `'block'` 与 `drawBlock` 交互，画完通过编辑请求让属性面板的名字输入框聚焦。
