# 规格：画布多选加减（点选 · 框选）

> Grill 2026-11-15：Q1–Q7 全按推荐。与左侧图层「Shift/⌘ 加减选」对齐。

## 行为（选择工具 V）

| 操作 | 效果 |
|---|---|
| 点未选对象 | 只选它 |
| 点已在多选里的对象（无修饰键） | 保持整组，可拖动 |
| **Shift 或 ⌘/Ctrl + 点** | 未选→加入；已选→松手且几乎未拖动则去掉 |
| 空白拖框 | 新选区 |
| **Shift/⌘ + 框选** | 并入现有选区 |
| **⌥ + 框选** | 从现有选区减去框内对象 |

不改手型、画笔、连线；不改光标教学。
