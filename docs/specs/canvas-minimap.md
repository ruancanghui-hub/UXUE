# 规格：图层 reveal · 画布鸟瞰

> Grill 2026-11-15：三轮全按推荐。

## 图层面板定位（reveal）

| 操作 | 效果 |
|---|---|
| 单击一行 | 选中；若该对象**未完整**落在当前视口内（含边距），只**平移**进来，**不改缩放**；已完全可见则视口不动 |
| Shift/⌘ 单击 | 加减选；只对**刚点的那一行**做 reveal |
| 双击 | 仍 `zoomToCard`（缩放并居中） |

范围：仅图层面板。属性面板等其它「选中」入口不改。

## 画布鸟瞰

| 项 | 决定 |
|---|---|
| 位置 | 画布区右下角；可收起，收起状态本机记住 |
| 内容 | 三个区域作底 + **全部卡片**色块；不画笔迹路径几何；选中加亮；当前视口用框标出 |
| 空项目 | 仍显示三区域 + 视口框 |
| 点击 | 视口中心跳到该世界坐标（短动画），**不改缩放** |
| 拖视口框 | 跟手平移；松手不另动画 |
| 形态 | 示意图，非真实缩略渲染 |
