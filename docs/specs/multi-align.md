# 规格：多选排齐

> Grill 2026-11-15：两轮全按推荐。

## 行为

| 动作 | 条件 | 相对 | 效果 |
|---|---|---|---|
| 左 / 水平居中 / 右 | ≥2 合格对象 | 选区包围盒 | 只改 x |
| 上 / 垂直居中 / 下 | ≥2 | 选区包围盒 | 只改 y |
| 水平均分 / 垂直均分 | ≥3 | 两端不动，中间外边缘间隙相等 | 按 x/y 排序，同坐标按 id |

## 合格对象

可移动卡片；**忽略**页面框、分组框、笔迹。混选时只排齐剩余合格者；不够则按钮/命令禁用。

## 入口

- 属性面板多选区：对齐 + 均分按钮
- ⌘K 命令（第一版无独立快捷键）
- 每次一条撤销（文案见 `ALIGN_LABELS`）

## 不做

固定间隙数值、相对最后选中、相对页面框、把页面/分组当控件齐。
