# 规格：素材清单与风格基准

> 术语以 [`CONTEXT.md`](../../CONTEXT.md) 为准：**素材清单、风格基准、视觉线索、核心素材**。  
> 决策来自 2026-11-14 grill 会话（Q1–Q11 全部采纳推荐项）。

## 0. 一句话

助手读生效主题卡（产品主题 → 产品是什么；视觉关键词 → 希望用户感受到什么；视觉线索 → 哪些元素能持续表达这种感觉），加一句可选范围说明，列出 8–16 项待设计的核心素材，直接落成核心素材区按类别分组的文生图提示词卡。挑一张满意的图设为**风格基准**，全部清单提示词卡绑定它做参考图，整套素材画风统一。

## 1. 已锁定的决策

| # | 决策 | 选择 |
|---|---|---|
| Q1 | 叫法 | **素材清单**；视觉线索是方向，清单项是具体交付物（名字、类别、用途、出自哪条线索） |
| Q2 | 输入 | 生效主题卡 + 可选一句范围说明 |
| Q3 | 形态 | 每项一张文生图提示词卡，核心素材区按类别分组框；提示词卡即「待生成」 |
| Q4 | 类别与数量 | 图标、插画、装饰元素、纹样 / 背景；8–16 项，图标为主 |
| Q5 | 入口 | 助手快捷按钮 + 主题卡属性按钮 |
| Q6 | 统一 | 风格基准：选图「以此为风格基准」，清单提示词卡绑定它为参考图并加一句画风参照 |
| Q7 | 提示词与参数 | 写清画什么、用在哪、构图、不要什么；1 张；图标 / 纹样 / 装饰方形，插画 3:2；质量中；附加主题规则 |
| Q8 | 再次列清单 | 追加新一批；助手拿到已有清单项名字避免重复 |

| Q10 | 基准来源 | 任意图像卡 |
| Q11 | 换 / 取消 | 同时只有一个基准；换基准替换绑定；取消则解绑并去掉那句参照 |

## 2. 数据模型

- `PromptCard.purpose` 增加 `'element'`。
- `PromptCard.styleRefCardId: string | null` —— 绑定的风格基准图像卡；它总是第 1 个输入（{{Image 1}}）。解析时图像卡不在就置 null。
- 助手输出增加 `elements: { name, category: 'icon' | 'illustration' | 'decor' | 'pattern', usage, cue, text }[]`。

## 3. 操作

- `applyElementList(state, drafts)`：每类一个分组框「素材清单 · 图标」等，放在核心素材区已有内容下方；组内 3 列网格，列宽留出输出图位置；提示词卡 `purpose: 'element'`、1 张、按类别定尺寸。
- `setStyleBenchmark(state, imageCardId | null)`：对全部清单提示词卡（输出就是这张图的除外）去掉旧基准输入和参照句，再把新基准放到第 1 个输入并在正文开头加参照句；null 即取消。
- 第一次生成时清单提示词卡的输出宽度固定 400，避免绑了大基准图后压住旁边的卡。
- 删除基准图像卡时，提示词卡的 `styleRefCardId` 置 null 并去掉参照句。

## 4. UI

- 助手：「从主题卡列出素材清单」（输入框里的文字作范围说明）。
- 主题卡属性：「列出素材清单」。
- 图像卡属性（项目里有清单提示词卡时）：「以此为风格基准」/「取消风格基准」。
- 清单提示词卡属性：显示当前风格基准。
