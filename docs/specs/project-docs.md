# 规格：项目文稿（PRD · 简报 · 设计规范 · AGENTS）

> 术语以 [`CONTEXT.md`](../../CONTEXT.md) 为准。ADR：[`0010`](../adr/0010-project-docs-on-disk.md)。  
> Grill 2026-11-14：Q1–Q12 全按推荐。

## 0. 一句话

在项目里放四类长 Markdown：能读、能改、能复制；设计规范可一键生成「设计规范图」到核心素材区。

## 1. 路径

| 角色 | 路径 |
|---|---|
| 产品需求文稿 | `docs/PRD.md` |
| 界面简报文稿 | `docs/界面简报.md` |
| 设计规范文稿 | `docs/设计规范.md` |
| 代理说明文稿 | `AGENTS.md`（项目根） |

打开或新建项目时若缺失则写入简短中文模板。

## 2. UI

- 左侧 **图层 | 文稿** 切换
- 文稿：四槽列表 → 编辑 / 预览 → 复制全文、Finder；设计规范另有「生成规范图」
- 自动保存（防抖）；外部改文件时刷新当前文稿（`fs` kind `docs`）

## 3. 生成规范图

1. 可选：助手把规范收成生图提示词；失败则用本地截断模板  
2. 核心素材区新建提示词卡「设计规范图」并提交文生图  
3. 结果按现有队列落成图像卡  

## 4. 非目标（本轮）

助手自动附带全文、PRD→写简报、三方向概念图、HTML 样板、CLAUDE.md。

## 5. 验收

- [x] 新项目有四份模板；旧项目打开时补齐缺失文件  
- [x] 可编辑保存、预览、复制、Finder  
- [x] 设计规范可触发生图（有 Key / mock 可测）  
- [x] `npm test` / `typecheck` 通过
