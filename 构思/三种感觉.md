# UI 从容感

一句话：**不是极简、不是空白，是界面不抢注意力、不制造焦虑，让用户觉得可控、稳定、不用费力猜，心里松弛**。
它是一种情绪体验，不只是视觉风格。

### 核心特征

1. **视觉上：有呼吸节奏，不拥挤、不炸眼**
   - 充足留白，元素不塞满屏幕；层级克制，**一页只突出一个主操作**，次要信息弱化，所有元素不互相抢视线
   - 配色低刺激：少高饱和强对比，主色、辅助色收敛，强颜色只留给真正需要警示的地方
   - 统一网格、对齐、间距，视觉稳定，没有忽大忽小、忽左忽右的杂乱感
2. **信息上：渐进披露，不一次性把复杂信息全部砸给用户**
复杂内容藏起来，需要的时候再展开；减少弹窗、强提醒、倒计时、限时紧迫感这类制造压力的设计
3. **交互与动效：克制、可预期、反馈温和**
   - 动画是服务状态说明，不是炫技；缓动柔和，不会弹跳、闪烁、突然弹出吓唬人
   - 反馈诚实、稳定，点了就知道状态；允许撤销、回退，不怕点错，容错高
   - 动效收尾稳，不抖动、不反复干扰视线
4. **全产品一致性：熟悉、可预判**
组件样式、按钮位置、弹窗逻辑、转场风格全程统一，用户不用反复学习新规则，降低认知负担UXmatters
5. **底层感受：界面 “隐身”，把焦点还给任务本身**
好的从容感 UI，用户注意力在自己要做的事，而不是在适应界面；界面安静、可靠、给人信任感，金融、健康、长时使用的工具类产品最看重这个



# UI 秩序感

一句话：**秩序感是一套可预测、有规则的视觉与信息框架，让用户一眼看懂结构、快速找到目标，减少思考成本**。它是从容感的底层基础；从容感是秩序带来的情绪结果。

## 核心要点

1. **网格系统**
所有元素对齐、按固定栅格排布，间距有规范，不是随手摆放。左右、上下对齐统一，不会东一个西一个。
2. **层级清晰**
通过字号、字重、颜色、间距、区块区分：标题→正文→辅助说明→备注。一眼分清谁重要、谁次要。
3. **重复一致性**
同类组件长得一样：按钮、卡片、输入框、图标、分割线全局统一。相同功能，位置、样式不变，用户不用重新理解。
4. **分组与就近原则**
相关信息抱团放在一起，用留白、卡片、分割线做区隔；物以类聚，视觉上能看出模块边界。
5. **流向（阅读顺序）**
引导视线按自然路径走：从上到下、从左到右，重点不随意跳变，不打乱浏览流。
6. **规则优先，特例少**
所有样式都有依据，特殊样式只用来做强调，不能到处都是特例。

# UI 克制感

一句话：**克制感 = 只放必要的东西，只在必要的时候强调，不额外增加视觉噪音、不主动抢夺用户注意力**。它是秩序、从容之外的审美约束。

> 
> 关系梳理：
> 秩序感是**骨架（规则）**；克制感是**取舍（做减法）**；从容感是最终给到用户的**情绪感受**。
> 有秩序不一定克制，有克制更容易带来从容。

## 核心要点

1. **元素克制：能不加就不加**
没有装饰性冗余元素，多余分割线、贴纸、花哨底纹、无关装饰全部拿掉；能用留白区分，就不用卡片、阴影。
2. **强调手段克制：强调方式收敛，不滥用**
高亮、主色、粗体、阴影、放大、动效，都是稀缺手段，**一页只给少数目标使用**；不能到处都是重点，等于没有重点。
3. **色彩克制：色彩有配额**
限定色板，不随便新增颜色；高饱和色、强对比只用于关键操作 / 警示，不铺满页面。
4. **动效克制：动画是服务，不是表演**
只用来表达状态变化（加载、展开、切换）；不做无意义弹跳、闪烁、持续吸引眼球的动画。
5. **文案克制：简短、精准，不啰嗦**
去掉营销话术、多余提示、重复说明；少弹窗、少打扰类提示。
6. **样式克制：不随意增加新样式**
不随便新增圆角、阴影、描边规格；在已有的组件体系里解决需求，特例越少越好。
